# neon-shelf-candle-collection-tracker

## Project Brief
Neon Shelf: Candle Collection Tracker
You're obsessed with candles — the scents, the brands, the burn times, the vibes. Build a single-page app called **Neon Shelf** where candle enthusiasts can catalog their collection and wishlist.

Each candle entry should capture: **name**, **brand**, **scent notes** (e.g. 'cedar, vanilla, smoke'), **vessel color/style**, **burn status** (unlit / burning / finished), and an optional **rating** out of 5. Users should be able to toggle between two views: **My Shelf** (candles they own) and **Wish List** (candles they want to buy).

Entries can be moved from Wish List to Shelf (simulating a purchase), and finished candles should be visually distinct — perhaps greyed out or crossed off. A small summary bar should show total candles owned, total burned through, and how many are on the wish list.

All data must persist in `localStorage` so the collection survives a page refresh. The UI should feel warm and atmospheric — think candlelight color palette, soft shadows, and cozy typography — making the app feel like a personal scented shrine rather than a sterile spreadsheet.

## Scoring
Three categories, each graded A+ to F, published before you submit, identical for every entry. Your grades and the written reasoning go public at the reveal.

### The three categories

Completeness (graded a+ to f)
Is everything the brief asked for present, reachable, and actually working - and how does the product behave off the happy path?

Problem fit + Design (graded a+ to f)
Does the solution fit the brief's real problem, how considered is the visual and responsive design, and is it clear to use end to end?

Technical + Craft (graded a+ to f)
Architecture and correctness, readability, security hygiene, and the attention to detail a rushed build doesn't have.
